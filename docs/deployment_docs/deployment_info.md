# Deployment Documentation: Render Web Services

## Overview
This document provides comprehensive deployment instructions for the Remote Servers Marketplace application on Render Web Services. The application is a FastAPI-based server-rental platform with PostgreSQL database, Supabase authentication, and Stripe payment processing.

## Prerequisites

### 1. Required Accounts
- **Render Account**: Sign up at [render.com](https://render.com)
- **GitHub Account**: For repository hosting
- **Supabase Account**: For authentication services
- **Stripe Account**: For payment processing (use Test Mode for development)

### 2. Repository Preparation
- Ensure your GitHub repository contains the complete application structure
- Verify `requirements.txt` includes all dependencies
- Confirm `app/main.py` is the entry point
- Test the application locally before deployment

### 3. External Service Configuration
Before deployment, configure the following external services:

#### Supabase Setup
1. Create a new Supabase project
2. Enable Email Auth in Authentication settings
3. Note the following credentials:
   - Project URL (SUPABASE_URL)
   - Anonymous Key (SUPABASE_ANON_KEY)
   - JWT Secret (SUPABASE_JWT_SECRET) - found in Project Settings > API

#### Stripe Setup
1. Create a Stripe account or use existing
2. Enable Test Mode for development
3. Generate API keys from Developer section:
   - Publishable Key (STRIPE_PUBLISHABLE_KEY)
   - Secret Key (STRIPE_SECRET_KEY)
4. Configure Webhooks:
   - Add endpoint: `https://your-render-url.onrender.com/api/v1/payments/webhooks/stripe`
   - Subscribe to `checkout.session.completed` and `payment_intent.succeeded` events
   - Copy the Webhook Signing Secret (STRIPE_WEBHOOK_SECRET)

## Environment Setup

### 1. Environment Variables
The following environment variables must be configured in Render:

| Variable | Description | Required | Example/Notes |
|----------|-------------|----------|---------------|
| `DATABASE_URL` | Render PostgreSQL connection URL | Yes | Auto-generated by Render |
| `PYTHON_VERSION` | Python runtime version | Yes | `3.12.0` |
| `STRIPE_PUBLISHABLE_KEY` | Stripe public key | Yes | `pk_test_...` |
| `STRIPE_SECRET_KEY` | Stripe secret key | Yes | `sk_test_...` |
| `STRIPE_WEBHOOK_SECRET` | Stripe webhook signing secret | Yes | `whsec_...` |
| `SUPABASE_ANON_KEY` | Supabase anonymous API key | Yes | `eyJhbG...` |
| `SUPABASE_JWT_SECRET` | Supabase JWT signing secret | Yes | 64-character hex string |
| `SUPABASE_URL` | Supabase project URL | Yes | `https://xxx.supabase.co` |
| `USE_REAL_STRIPE` | Use real Stripe (vs mock) | No | `true` for production |

### 2. Local Development Environment
For local development, create a `.env` file with the same variables, using local PostgreSQL:

```bash
DATABASE_URL=postgresql://user:password@localhost:5432/marketplace
PYTHON_VERSION=3.12.0
STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
# ... other variables
```
